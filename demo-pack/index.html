ai-doc-lint 零成本一键演示指南

给业务方/领导/同事演示项目：一条命令本地起、一条命令出公网地址，无需任何云服务器与费用。
零成本 无云服务器 一键启动 demo_start.ps1 外网临时域名 trycloudflare.com 用完即关 零残留

1 演示包内容

本文件夹（demo-pack/）即完整交付物，拷到任意 Windows 电脑即可演示：

  • PS scripts/demo_start.ps1演示主脚本（一键起服务 / 一键开公网隧道）
  • M 本指南（index.html）演示步骤与实测记录

cloudflared 隧道程序无需随包携带：脚本会自动定位已安装版本，未安装时自动从官方 GitHub 下载（约 40MB，仅首次）。

2 演示前准备（一次性）

  • 安装 Docker Desktop（Docker Engine 28+）并启动，确认右下角鲸鱼图标正常。
  • 把项目放到本机（仓库 D:\projects\ai-doc-lint 或拷入的目录），复制 .env.example 为 .env 并填入密钥/大模型 Key（演示可不配 LLM，规则检查全部 0 token 可跑）。
  • 首次启动构建镜像（约 5-10 分钟，取决于网络）：
PS> cd D:\projects\ai-doc-lint
PS> docker compose up -d --build
初始化管理员：首次打开 http://localhost:8080 会进入「初始化管理员」页面，仅可创建一次，请提前创建演示账号。

3 一键本地演示

一条命令：自动检查 7 个容器是否健康（未就绪自动拉起），并打开浏览器：

PS> powershell -ExecutionPolicy Bypass -File scripts-dev\demo_start.ps1

脚本执行效果：

  • 输出 容器: 7/7 healthy 与 本地服务就绪: http://localhost:8080；
  • 自动打开浏览器进入工作台，即可演示：上传合同 → 校验报告 → 销项 → 原文对照 → 导出意见书/明细；
  • 顺带演示首页看板（严重度分布、最近上传）、版本对比、交叉比对、文档助手、规则配置等全部功能。

4 一键外网演示（给不在身边的人看）

加 -Remote 参数，脚本自动建立 Cloudflare 免费隧道，打印临时公网地址：

PS> powershell -ExecutionPolicy Bypass -File scripts-dev\demo_start.ps1 -Remote

使用要点：

  • 脚本自动定位 cloudflared（已安装 / winget 安装 / 自动下载三条路径兜底）；
  • 约 10 秒后输出形如 https://xxxx-xxxx-xxxx.trycloudflare.com 的公网地址，把该地址发给观众即可访问；
  • 演示结束按 Ctrl+C 停止隧道，公网地址立即失效、无任何残留。
临时隧道无 uptime 保证，仅供演示；观众看到的是本机实时画面，但合同等数据仍全部保存在本机，不经过任何第三方存储。

7 常见问题

演示时没有大模型 Key 能跑吗？

能。格式/错别字/条款完整性/金额勾稽等核心检查全部本地 0 token 运行；对话助手、深度条款审查等 LLM 功能在未配 Key 时会降级提示，不影响主体演示。

脚本报「cloudflared 未安装」怎么办？

脚本会先自动下载；若网络受限，手动执行 winget install Cloudflare.cloudflared 后重试。

外网地址每次都不一样？

是。临时隧道每次生成随机域名，演示时把当次地址发给观众即可；如需固定地址再评估付费方案。

观众需要装任何东西吗？

不需要，用浏览器打开公网地址即可，手机/电脑均可访问。
